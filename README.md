# Pawchive Image Expander

Automatically shows full-size images on Pawchive post pages instead of thumbnails. Creator pages are left alone, so it won't load every image at once.

Works on Chrome, Edge, Brave and Firefox.

<img width="1605" height="554" alt="Example of the extension" src="https://github.com/user-attachments/assets/f0990ea8-045c-44bd-950c-a71f36b91a98" />

## Download

**[Download pawchive-image-expander.zip](https://github.com/KS-AO-HUB/Kemono-Image-Expander/releases/latest/download/pawchive-image-expander.zip)**

Right-click the zip and choose **Extract All**.

## Install on Chrome

1. Click the three dots at the top right.
<img width="1908" height="967" alt="image" src="https://github.com/user-attachments/assets/12182c40-4567-4e17-b62f-8c9ab6864efe" />

2. Click **Extensions**, then **Manage Extensions**.
<img width="1919" height="1015" alt="image" src="https://github.com/user-attachments/assets/0d247610-8a52-4960-92e8-5c4043f07850" />

3. Turn on **Developer mode** (toggle at the top right).
<img width="1919" height="279" alt="image" src="https://github.com/user-attachments/assets/64edf11e-0af1-4c54-8d39-11137f2385af" />

4. Click **Load unpacked**.
<img width="570" height="270" alt="image" src="https://github.com/user-attachments/assets/192e15b2-8ccf-43c1-a529-8fec7b0b0b07" />

5. Select the `extension` folder, then refresh Pawchive.
<img width="952" height="593" alt="image" src="https://github.com/user-attachments/assets/b2e10ad9-b5a5-4aae-bbd4-2e30fbd40121" />

## Install on Firefox

1. Type `about:debugging#/runtime/this-firefox` in the address bar.
2. Click **Load Temporary Add-on**.
3. Open the `extension` folder and select `manifest.json`, then refresh Pawchive.

Firefox removes it when you close the browser, so you'll need to load it again next time.
